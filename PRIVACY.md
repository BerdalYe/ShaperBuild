# Privacy

ShaperBuild does not collect personal data.

- There are no accounts, no tracking, no analytics and no advertising.
- Designs, settings, saved versions, thumbnails and crash-recovery copies
  are stored only on your computer (in the folders you choose and in the
  app's own data folder).
- **Update check:** when it starts, and every few hours while it runs,
  ShaperBuild asks GitHub (github.com, run by GitHub, Inc.) whether a newer
  version has been published. Like any web request, this lets GitHub see
  your computer's IP address. No design data or personal information is
  sent. You can turn this off in Settings (*Check for updates
  automatically and install them on restart*); see GitHub's privacy statement for what GitHub does with
  the request.
- Links in the app (for example to the source code) open in your own web
  browser.

Questions: open an issue on the project's GitHub page.
